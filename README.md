🌦️ Weather Dashboard

📌 About the Project

The Weather Dashboard is a web-based application that displays weather information for a selected city. It helps users check current weather conditions, temperature, humidity, and other weather details in a simple and user-friendly interface.

🎯 Features

- Search weather by city name.
- Display current temperature.
- Show weather conditions.
- Display humidity and wind speed.
- Simple and user-friendly interface.
- Responsive design for different screen sizes.

🛠️ Technologies Used

- HTML – For webpage structure.
- CSS – For styling and layout.
- JavaScript – For functionality and dynamic updates.
- Weather API – To fetch real-time weather data (if implemented).

⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Enter a city name to view its weather information.
